# 特勞特 vs 顧均輝：師徒視角對照表
### 用兩個定位之眼看福智集團 · 2026-08-07

> **免責**：本表基於兩位思想者公開言論與著作推斷，非本人觀點。特勞特＝定位理論創始人；顧均輝＝其學生、《定位》四大名著中譯者。

---

## 一、基本盤對照

| 維度 | 傑克·特勞特 | 顧均輝 |
|---|---|---|
| 身分 | 定位理論創始人 | 特勞特學生、中譯者、落地執行者 |
| 理論核心 | 如何在顧客心智中與眾不同 | 如何讓定位落地成能算賬的增長 |
| 服務對象 | 跨國企業（AT&T、西南航空、七喜） | 中國本土企業（台鈴、半畝花田、伊利） |
| 語言風格 | 直白斷言、像戰略顧問 | 江湖氣金句、像打仗的老闆 |
| 核心詞彙 | 心智階梯、差異化、戰場、魚 | 反人性、認知、聚焦、成果在外不在內 |
| 一句話定位 | 第一比更好更重要 | 優秀的戰略定位都是反人性的 |

## 二、心智模型對照

| # | 特勞特模型 | 顧均輝模型 | 對福智的推論（同/異） |
|---|---|---|---|
| 1 | **心智階梯**：品類在顧客腦中排成階梯，第一、二名才有意義 | **認知即戰場**：商戰本質是認知戰，心智階梯才是戰場 | 同：福智在宗教階梯無位、里仁在有機階梯有位但掛錯名 |
| 2 | **差異化即生存**：沒有差異只能打價格戰 | **先找敵人，再定自己**：搶佔競爭對手留下的空間 | 同：先看慈濟/棉花田佔了什麼，再找福智能贏的空位 |
| 3 | **知覺優先，事實第二**：心智裡沒有事實，只有知覺 | **成果在外不在內**：市場怎麼記你才算數，內部感受不重要 | 同：里仁有知覺/成果，但都沒回灌成福智 |
| 4 | **競爭導向**：由外而內，攻擊對手強勢中的弱點 | **反人性戰略**：大家都往東，你往西 | 同結論不同路徑：特勞特找品類空缺，顧均輝找人性逆反 |
| 5 | **犧牲與聚焦**：想得到所有就失去所有；品牌延伸是稀釋 | **聚焦一件事**：要嘛第一，要嘛佔住第一；避免品牌延伸 | **異**：特勞特＝減法（砍事業）；顧均輝＝重組（重新排位） |

**核心分歧就一條**：特勞特主張「佔住心智位置即贏」，顧均輝要求「佔位＋能算賬的成長數字」。

## 三、決策啟發式對照

| 主題 | 特勞特 | 顧均輝 |
|---|---|---|
| 第一步 | 先問差異點，再問戲劇化 | 先問敵人，再問自己 |
| 思考方式 | 像魚一樣思考（站在顧客知覺裡） | 選擇大於努力（先算清楚賽道） |
| 對心智 | 不試圖改變心智，運用既有認知 | 朝無人之處走（跟風時立刻停） |
| 對競爭 | 攻擊對手的強勢弱點；領導者自我攻擊 | 敢戳同行的話（別照單全收行業慣例） |
| 誠實 | 誠實法則：承認缺點，回贈優點 | 先活進方法論裡（自己敢用自己才信） |
| 聚焦 | 犧牲法則：要得到什麼就放棄什麼 | 談結果必給可算的數字（台鈴70→200億） |

## 四、對福智集團的診斷對照

| 診斷項 | 特勞特會說 | 顧均輝會說 |
|---|---|---|
| 問題本質 | 沒有在顧客心智階梯佔位；里仁的階梯沒「過戶」給福智 | 不敢承認自己是集團；九個法人沒人為母品牌工作 |
| 最大敵人 | 心智空白＋慈濟（慈善已佔死）＋棉花田（有機已被里仁佔但掛錯名） | 「無感」＋「成果掛在別人名下」 |
| 戰略姿態 | 開創新品類（宗教＋有機零售的第一） | 重新排位（入口/中段/地基） |
| 對九法人 | 品牌延伸，心智被稀釋——該縮 | 九盤棋各自為政——該排位不該散架 |
| 對內部 | 不談管理 | 對外反人性、對內順人性（顧好十萬學員） |
| 對爭議 | 先清心智，別試圖改變已形成的心智 | 信任鏈是命門，先清信任＋公開數字 |
| 驗收標準 | 佔住位置即贏 | 位置＋可算的成長數字才算贏 |

## 六、給決策者的結論

| 維度 | 勝出者 | 原因 |
|---|---|---|
| 診斷純度 | 特勞特 | 一句話戰略更乾淨 |
| 可落地性 | 顧均輝 | 重組派＋順人性管理，適合已成型的集團 |
| 對福智整體 | **顧均輝** | 福智砍不動事業，但能重新排位；且宗教集團特別需要「對內順人性」 |

**最終一句**：
- 特勞特：「別試著改變心智，把里仁已經佔住的位置過戶給福智。」
- 顧均輝：「入口在前，靈魂在後。門開多大，家就有多大。」
