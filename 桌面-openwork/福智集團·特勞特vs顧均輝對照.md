# 特勞特 vs 顧均輝：用兩個定位之眼看福智集團
### 對照分析 · 2026-08-07

> **免責**：本報告以兩位思想者的公開言論與著作為基礎推斷，非本人觀點。特勞特＝傑克·特勞特（定位理論創始人），顧均輝＝特勞特學生、其四大名著中譯者。

---

## 一句話結論

**師徒同源，卻差在一個「狠」字。** 特勞特看福智，會說「你的問題是沒有在顧客心智裡佔一個位置」；顧均輝看福智，會說「你的問題是你不敢承認自己是集團、不敢佔那個位置」。**特勞特教你站在階梯的哪一階，顧均輝教你先把梯子搬到自己腳下。**

---

## 一、師徒關係：同一個理論，兩種中國用法

| | 特勞特 | 顧均輝 |
|---|---|---|
| 關係 | 定位理論的**創始人** | 特勞特的**學生、中譯者**（譯《定位》《與眾不同》《商戰》《重新定位》） |
| 核心命題 | 「如何讓自己在顧客心智中與眾不同」 | 「如何讓定位落地成**能算賬的增長**」 |
| 服務對象 | 跨國企業、全球市場（AT&T、西南航空、七喜） | 中國本土企業（台鈴、半畝花田、伊利、利郎） |
| 語氣 | 直白、簡潔、斷言式，像戰略顧問 | 江湖氣、口語、金句連發，像打仗的老闆 |
| 最愛用的詞 | 心智階梯、差異化、戰場、魚 | 反人性、認知、聚焦、成果在外不在內 |

**關鍵差異一句話**：特勞特是「學院派的戰略家」，顧均輝是「實戰派的落地工」。**理論上顧均輝沒有增加任何東西，但他在執行層把定位從「書」變成了「賬」。**

## 二、核心分歧：五個維度的正反面

### 分歧一：差異化的來源——「做第一」vs「反人性」

| | 特勞特 | 顧均輝 |
|---|---|---|
| 核心主張 | **第一比更好更重要**（It's better to be first than to be better）——開創新品類，做新品類的第一 | **反人性戰略**——大家都往東，你往西，敢做別人不敢做的事 |
| 對福智的推論 | 福智該**開創「宗教＋有機零售」新品類**，成為唯一 | 福智該**做全台灣沒人敢做的事——把開店講成修行** |
| 差異點 | 兩者結論相近，但出發點不同 | 特勞特從「品類空缺」出發，顧均輝從「人性逆反」出發 |

**對照結論**：福智的例子恰好兩者皆通——「有零售出口的佛教集團」既是特勞特的「新品類第一」，也是顧均輝的「反人性空檔」。**同一個答案，兩種論證。**

### 分歧二：戰場的定義——「心智」vs「認知＋成果」

| | 特勞特 | 顧均輝 |
|---|---|---|
| 戰場 | **心智（Mind）**——顧客腦中的階梯，市佔率從第三名後戲劇性下滑 | **認知（Cognition）＋成果**——腦中的位置只是第一步，還要有能算的數字 |
| 對福智的推論 | 福智的心智階梯裡沒有位置，里仁有位置但不屬於福智 → 必須把里仁的階梯「過戶」給福智 | 同樣結論，但加一句：**里仁的營收、門市、來客數必須變成可驗證的成長數字**，否則只是嘴上定位 |
| 差異點 | 特勞特停在「佔位」，顧均輝要求「佔位＋算賬」 | 顧均輝的獨特貢獻：把定位的驗收標準從「知覺」拉到「數字」 |

**對照結論**：特勞特會說「知覺優先，事實第二」——佔住位置就贏；顧均輝會說「**成果在外不在內**」——位置佔了，市場沒買單，等於沒佔。**這正是師徒最深的裂縫：特勞特相信心智，顧均輝還相信錢。**

### 分歧三：對「產品」的態度——「知覺優先」vs「順人性管理」

| | 特勞特 | 顧均輝 |
|---|---|---|
| 對外 | 行銷是知覺的戰爭，不是產品的戰爭 | 戰略對外要反人性（對自己狠） |
| 對內 | 鮮少談管理 | **管理對內要順人性**（對客戶、員工好）——這是顧均輝的核心張力 |

**對照結論**：特勞特的理論是「單向」的——只談怎麼打外部戰爭；顧均輝補了「內向」的一刀——**對外狠、對內軟，兩邊不能搞反。** 對福智來說，這意味著：對外要敢說「我是集團、我要做生意」（反人性），對內要顧好十萬學員的情緒與僧團的戒律（順人性）。**特勞特只給外藥，顧均輝給外藥加內補。**

### 分歧四：對「擴張」的態度——「犧牲聚焦」vs「攤子再大也要聚焦」

| | 特勞特 | 顧均輝 |
|---|---|---|
| 主張 | 犧牲法則：想得到所有東西，就會失去所有東西；**品牌延伸是心智的稀釋** | 聚焦一件事：要嘛做成第一，要嘛佔住第一的位置；**攤子越大越要問「誰在顧客腦子裡有位置」** |
| 對福智的推論 | 九個法人九個名字＝**九次品牌延伸**，心智已被稀釋到零 | 九個法人九個名字＝**九盤棋各自為政**，沒人為母品牌工作 |
| 差異點 | 特勞特會建議「砍掉大半事業」 | 顧均輝會建議「**不用砍，但必須重新排位**」——九柱一屋，分工不散架 |

**對照結論**：這是最實質的分歧。**特勞特是「減法派」——福智該縮；顧均輝是「重組派」——福智該排。** 因為顧均輝見過中國企業的現實：你叫一個已成型的集團砍事業，他砍不動。但你可以叫他把入口、中段、地基重新排位——里仁站前、佛教基金會退後。**特勞特要的是「重新定位」，顧均輝給的是「可執行的重新定位」。**

### 分歧五：對「爭議」的態度——「信任即位置」vs「信任鏈是命門」

| | 特勞特 | 顧均輝 |
|---|---|---|
| 主張 | 心智一旦形成極難改變；別試圖改變心智，運用既有認知 | 定位再漂亮，**信任鏈一斷全毀**；先處理爭議，再談佔位 |
| 對福智的推論 | 福智的爭議（接班人、中資疑雲）已經佔了部分心智——**先清心智，再談定位** | 同樣結論，但要求更狠：**把「台資＋社會企業＋資金透明」講成公開事實**，用數字證明 |

## 三、兩人會怎麼重排福智：同一個答案的兩種說法

### 特勞特版（如果他是福智顧問）
> 你問我福智怎麼定位？先告訴我：**顧客心智的階梯裡，福智站在哪？** 答案是你沒站。里仁站在「有機」第一階，但你沒把那階梯過戶給福智。兩個方法：**一，開創新品類——「宗教＋有機零售」的第一；二，把里仁這個已佔住的位置，變成福智的位置。** 差異點有了——全台灣唯一「法師留下的店」——然後怎麼戲劇化？把它講成一個故事。**別試著改變心智，運用里仁已經佔住的認知。**

### 顧均輝版（如果他是福智顧問）
> 聽我說，福智的問題不是沒位置，是**不敢承認自己有位置**。里仁就是你的位置，但里仁不知道自己是福智的，福智不知道自己的位置在里仁。九個法人九盤棋，沒人為「福智」兩個字做功課。**我不叫你砍事業，我叫你排位：里仁站前當入口，佛教基金會退後當地基。** 對外反人性——大家往神聖走，你往生活走；對內順人性——顧好十萬學員。但你要記住：**光佔位置不算數，里仁的來客數、營收、知名度，每一項都要能算賬。**

## 五、給決策者的總對照

| 維度 | 特勞特 | 顧均輝 | 誰適合福智 |
|---|---|---|---|
| 診斷視角 | 心智階梯、差異化 | 反人性、成果在外 | 兩者互補 |
| 戰略姿態 | 開創新品類、做第一 | 重新排位、聚焦入口 | 顧均輝（福智已成型，砍不動） |
| 執行深度 | 戰略到「戲劇化」為止 | 戰略到「能算賬的增長」 | 顧均輝 |
| 對內管理 | 不談 | **順人性管理（對內軟）** | 顧均輝（宗教集團特別需要） |
| 對爭議 | 先清心智 | 先清信任鏈＋數字 | 顧均輝 |
| 語言 | 戰略顧問 | 打仗的老闆 | 看聽眾 |

**最終判斷：師徒會給福智同一個戰略（里仁入口、福智母品牌），但特勞特給方向，顧均輝給步驟。** 對福智這種「九個法人、十萬學員、充滿內部情緒」的集團，**顧均輝的重組派＋順人性管理，比特勞特的減法派更可落地。** 但如果要的是「一句話戰略的純度」，特勞特更乾淨。

**收尾一句（特勞特口吻）**：別試著改變心智，把里仁已經佔住的位置過戶給福智。
**收尾一句（顧均輝口吻）**：入口在前，靈魂在後。門開多大，家就有多大。
