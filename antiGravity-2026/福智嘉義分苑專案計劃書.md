# 福智嘉義分苑發展專案：分工與執行計劃書

本計劃書針對福智嘉義分苑的四大核心任務（過去運作軌跡、分苑核心價值、未來結構與營收單位、跨界合作平台）進行結構化拆解，並規劃相應的階段、角色分工與執行步驟。

## 四大任務執行方案

### 1. 過去運作軌跡（文獻與口述歷史）
*   **目標**：梳理嘉義分苑自成立以來的重大事件、核心人物、重要專案與社會影響力，形成歷史檔案。
*   **具體做法**：
    *   **資料收集**：整理歷年活動照片、會議記錄、刊物與報告。
    *   **深度訪談**：訪問資深同修、歷任分苑長與關鍵推動者（預計 5-8 位）。
    *   **軌跡編撰**：繪製「嘉義分苑發展大事記時間軸」，並撰寫紀實文章。
*   **交付物**：`嘉義分苑運作軌跡里程碑報告`、`口述歷史訪談錄音與逐字稿`。

### 2. 分苑核心價值（定位與精神凝聚）
*   **目標**：明確嘉義分苑在福智團體中的獨特定位，並凝聚內部共識。
*   **具體做法**：
    *   **問卷調查**：針對內部同修與義工發放核心價值認知問卷。
    *   **共識工作坊**：舉辦 1-2 場「核心價值凝聚工作坊」，透過焦點團體討論，提煉出分苑的「願景、使命、核心價值（Vision, Mission, Values）」。
    *   **價值視覺化**：將核心價值轉化為易於傳播的標語（Slogan）與視覺文宣。
*   **交付物**：`核心價值定義書`、`分苑願景與定位白皮書`。

### 3. 未來結構面相，設立營收單位（永續營運）
*   **目標**：設計符合法規且能支持分苑長期運作的營收單位（如社會企業、蔬食推廣、文創產品或心靈工坊）。
*   **具體做法**：
    *   **市場與法規調研**：評估非營利組織（NPO）設立營利事業的法規限制，並分析嘉義當地的綠色/蔬食/教育市場。
    *   **商業模式設計**：運用商業模式圖（Business Model Canvas）設計營收單位的獲利模式。
    *   **組織架構重組**：規劃「公益部門」與「營收部門」的防火牆機制與權責分工。
*   **交付物**：`營收單位可行性評估與商業計劃書`、`未來組織架構圖`。

### 4. 跨界合作平台（以品德教育為例）
*   **目標**：以品德教育、生態環保等議題為核心，鏈結政府、學校、企業與社區，擴大社會影響力。
*   **具體做法**：
    *   **利害關係人地圖**：盤點嘉義地區的國中小學、大專院校、在地企業與政府教育局處。
    *   **合作方案規劃**：設計「品德教育推廣企劃」（如校園講座、親子共讀、生活實踐營隊）。
    *   **平台機制建立**：制定合作備忘錄（MOU）範本，並規劃定期的跨界聯席會議。
*   **交付物**：`品德教育跨界合作企劃書`、`合作夥伴意向書檔模版`。

## 團隊角色分工 (RACI 矩陣)

為了確保每項任務都有人負責且決策清晰，建議設立以下角色：
*   **專案總召 (Sponsor)**：負責整體方向決策與資源協調。
*   **歷史文化組 (組長+組員)**：專責軌跡與核心價值。
*   **營運發展組 (組長+組員)**：專責營收單位規劃與財務。
*   **外聯合作組 (組長+組員)**：專責跨界合作與品德教育推廣。

| 任務項目 | 專案總召 | 歷史文化組 | 營運發展組 | 外聯合作組 |
| :--- | :---: | :---: | :---: | :---: |
| **1. 過去運作軌跡** | I | **A/R** | C | - |
| **2. 分苑核心價值** | A | **R** | C | C |
| **3. 未來結構與營收** | A | - | **R** | C |
| **4. 跨界合作平台** | A | - | C | **R** |

> **R** (Responsible): 實際執行者 | **A** (Accountable): 最終負責/決策者 | **C** (Consulted): 諮詢對象 | **I** (Informed): 被通知者

## 後續推進建議步驟

1.  **召開啟動會議 (Kick-off Meeting)**：確認各組名單與召集人。
2.  **細化工作分解結構 (WBS)**：各組根據上述做法，列出更詳細的雙週工作進度。
3.  **設立檢核節點**：每雙週召開進度匯報，確保「過去軌跡」與「核心價值」的產出能順利導向「未來結構」與「跨界合作」的設計。
